# 🍄 木木的树洞

**慢慢说，也可以不说。**

木木住在一棵亮着小灯的树里。你是一只小香菇，可以走到长椅上坐一会儿，也可以在树下铺开信纸。木木听你说，不急着分析，不用每封回信都追问。

这是一个以陪伴为主题的个人探索项目，提供无需密钥的公开演示，以及使用自己的 OpenAI API Key 运行的私人本地版。

## 两种体验

| | 公开演示 | 私人本地版 |
|---|---|---|
| 坐一会儿、写信、寄信动画 | ✓ | ✓ |
| 回信 | 标注清楚的预写示例，与来信内容无关 | 通过 OpenAI Responses API 生成 |
| API Key | 不需要，也没有填写入口 | 仅在自己电脑的 `.env` 配置 |
| 模型调用费用 | 无 | 使用自己的 API 项目额度 |
| 信件保存、匿名社区 | 未实现 | 未实现 |

小香菇会随操作走向长椅、在地上写信、举着信来到树洞门口。页面适配手机、浅色／深色模式，也尊重系统的减少动态效果设置。

## 快速体验

需要 **Node.js 22 或更高版本**。项目没有第三方运行依赖，不需要 `npm install`。

```sh
npm run demo
```

打开终端显示的本地地址，默认是 <http://127.0.0.1:8787>。此命令强制使用演示模式，即使环境中有密钥也不会调用模型。

也可以直接用静态服务器托管 `public/` 文件夹。该文件夹本身就是完整的公开演示。

## 开启自己的真实回信

1. 在 [OpenAI API 平台](https://platform.openai.com/api-keys) 为你自己的 API 项目创建密钥，并确认该项目有可用额度。领取过订阅 API 福利的用户，需要使用关联组织下的项目。
2. 在项目根目录复制配置模板：

   ```sh
   cp .env.example .env
   ```

3. 用本地编辑器打开 `.env`，填写 `OPENAI_API_KEY`，并将 `OPENAI_MODEL` 设为你的项目可调用的普通文本模型。模板中的 `gpt-6.1-sol` 是可替换的配置示例，实际可用性以你的 API 项目为准。
4. 启动：

   ```sh
   npm start
   ```

5. 打开 <http://127.0.0.1:8787>，看到“私人本地版 · AI 回信已配置”后，写信并勾选“希望木木回一封信”。只有寄出这类信件时才会调用 API。“已配置”只说明本地配置齐全，不代表密钥权限或余额已验证。

修改 `.env` 后需重启服务。按 `Ctrl+C` 停止。请勿把密钥粘贴进网页、截图、聊天、README 或 GitHub 仓库。`.env` 已加入 `.gitignore`；模板不含密钥。

没有勾选回信时，信件不会发送到服务器。发生超时、额度不足等错误时保留输入，不自动重试收费请求。你可以手动重试；已发出的失败或中断请求仍可能产生 API 用量。

## 发布到 GitHub Pages

仓库内置 `.github/workflows/pages.yml`：

1. 把项目上传到自己的 GitHub 仓库，默认分支命名为 `main`。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 推送 `main` 或手动运行 **Publish demo** 工作流。
4. 工作流完成后，在 Pages 设置里打开演示地址，并把它填入仓库的 Website 字段、固定到个人主页。

工作流运行检查后，**只发布 `public/`**。它不读取 API Key，不需要配置 GitHub Secrets，也不会启动私人后端。GitHub Pages 上的演示始终显示示例回信。

真实回信供下载项目的人在本机自行运行。不要把密钥注入网页构建产物：即使来自 GitHub Secrets，打包进 JavaScript 后仍然会公开。

## 木木的回信

提示词在 [`prompts/mumu.txt`](prompts/mumu.txt)，可以独立阅读、修改。

- 默认陪伴，不连续追问，不强行分析情绪。
- 用户明确请求时，再一起梳理或想办法。
- 不假装记得没有提供的经历，不承诺排他关系或永远陪伴。
- 提供情绪支持，不做心理诊断或治疗；明确的即时危险优先现实支持。

本版每次只发送当前信件，没有多轮记忆。提示词是产品行为约定，不是临床有效性保证。

## 数据与边界

- 无分析追踪、无数据库，不写入本地存储，也不在应用日志记录信件。
- 信件和回信只保留在当前页面内存，可点“清空本页信件”；刷新或关闭后清空。
- 真实回信会把当前信件和提示词发送给 OpenAI，使用 `store: false` 关闭响应存储；这不等于服务提供方不保留任何数据。相关处理以 [OpenAI API 数据说明](https://developers.openai.com/api/docs/guides/your-data) 为准。
- 私人服务仅监听 `127.0.0.1`，限制浏览器来源、请求大小和并发，只返回白名单内的静态资源。请勿将它直接暴露到公网；本项目没有公共服务需要的用户认证与配额体系。
- 尚未实现持久化信箱、匿名交流或付费功能。

## 开发与验证

```sh
npm run check
npm test
```

测试使用模拟模型响应，不消耗 API 额度，覆盖模式隔离、文件访问、来源限制、输入校验、生成结果、错误脱敏与超时。真实模型的中文语气和安全表现仍需在自己的 API 配置完成后试用验证。

```text
public/                 公开演示页面与角色动画（唯一发布目录）
server.mjs              仅供本地使用的 API 服务
prompts/mumu.txt        木木的陪伴提示词
.env.example            不含密钥的配置模板
test/                   不调用真实 API 的服务测试
.github/workflows/      仅部署演示版的 GitHub Pages 工作流
```

界面与角色使用 HTML/CSS 绘制，不依赖外部字体、图片服务或前端框架。
